## Level 0: Tech foundations (non-tech beginner)

- What the tech industry is: software, hardware, cloud, who does what
- How the internet works: IP, DNS, HTTP/HTTPS, ports
- What a server is, and what an operating system is
- Command line basics (Linux terminal, files, permissions)
- What an application is: frontend, backend, database
- Git and GitHub basics

## Level 1: Core infrastructure

- Linux administration (users, services, networking, logs)
- Networking essentials (subnets, firewalls, load balancers, SSL/TLS)
- Scripting with Bash and basic Python or PowerShell
- Virtualization and an intro to cloud (IaaS, PaaS, SaaS)

## Level 2: Cloud fundamentals (your Azure strength)

- Cloud concepts and shared responsibility
- Azure core services: compute, storage, networking, identity
- Identity and access (Entra ID, RBAC)
- Resource organization: subscriptions, management groups
- AZ-104-level administration

## Level 3: DevOps core

- DevOps culture and the software delivery lifecycle
- CI/CD with GitHub Actions, GitLab CI and Azure DevOps
- Docker and containers
- Infrastructure as Code with Terraform (state, modules, workspaces)
- Secrets management with Vault and Key Vault
- Intro to monitoring and logging

## Level 4: Kubernetes and DevSecOps

- Kubernetes architecture and workloads (CKA-Level)
- AKS and Rancher, Helm, ingress and networking
- Observability with Prometheus, Grafana and alerting
- DevSecOps: Trivy, Gitleaks, Bandit, policy as code
- GitOps (ArgoCD or Flux)

## Level 5: Platform engineering

- Why platform engineering exists and how it differs from DevOps and SRE
- Platform as a product: treating developers as customers
- Internal Developer Platforms (IDP) and golden paths
- Developer portals (Backstage), templates and self-service
- Reusable Terraform modules and landing zones
- Multi-tenancy, environments and automated patching
- Platform metrics: DORA, developer experience, adoption

## Level 6: Consultant level

- Assessing an organization’s maturity and gaps
- Cloud architecture and enterprise landing zone design
- FinOps and cost optimization
- Security, compliance and governance (public sector, regulated industries)
- Migration strategy, such as on-prem to cloud and hybrid
- Platform team structure, roadmaps and build vs buy decisions
- Stakeholder communication, proposals and writing technical reports
- Leading teams and handling delivery risk
